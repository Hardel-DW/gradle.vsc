Gradle side panel for VS Code, listing and running the Gradle tasks of the workspace.
Made after dropping the Microsoft and Red Hat Java packs for the JetBrains "Java and Kotlin by IntelliJ IDEA" extension only, to get the Gradle tabs back, lighter and less buggy.
Requires VS Code 1.139 or newer.

Features:
- Scans the workspace folders and shows the Gradle tasks of every build and module.
- Runs tasks, or debugs them with the JetBrains debugger.
- Hides the modules you do not use.
